# Mini-projet 5MLDE — Prévision de la demande de vélos en libre-service

Industrialisation d'un modèle de régression qui prévoit le nombre de locations horaires (`cnt`)
du service Capital Bikeshare (jeu UCI Bike Sharing, 2011-2012).

```sh
uv sync --locked
uv run --locked python main.py --config config/config.json
uv run --locked python -m pytest -q
```
